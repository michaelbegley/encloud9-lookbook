enCloud9 BRAND KIT (Look 9)

START HERE
Open "enCloud9 Style Sheet.pdf" (or the .html version in a browser). It shows the logo,
colours, fonts and buttons on one page, with the rules for using them.

WHAT IS IN THIS ZIP
  enCloud9 Style Sheet.pdf     The style sheet, for reading and printing
  enCloud9 Style Sheet.html    Same page; open in a browser; click a colour to copy its hex code
  enCloud9 Colours.csv         Every colour with hex and RGB values and what it is for
  logo/                        The enCloud9 wordmark, blue (for light backgrounds) and white
                               (for dark backgrounds), as SVG (any size) and PNG (transparent)
  fonts/Hanken Grotesk/        The main font: static/ for installing on your computer,
                               variable/ for web designers, OFL.txt licence
  fonts/DM Mono/               The label font for small labels, prices and numbers, OFL.txt licence
  office/                      Colour and font themes for Word and PowerPoint

THE SHORT VERSION
  Brand blue     #355DA6  (RGB 53, 93, 166). Main buttons and one highlight per page or graphic.
  Dark ink       #0E1A3A  (RGB 14, 26, 58). Text and dark backgrounds.
  Page           #F7F9FC. Light background.
  Main font      Hanken Grotesk. Regular for text, SemiBold for headlines and buttons.
  Label font     DM Mono, small, in capitals. Labels, prices and numbers only.
  Corners        Square. No rounded corners, except email buttons (4 px).
  Logo           Wordmark only. The cloud symbol is retired.

INSTALL THE FONTS
  Windows: open fonts/Hanken Grotesk/static, select all the .ttf files, right-click, Install.
           Do the same in fonts/DM Mono. Restart Word or PowerPoint.
  Mac:     double-click each .ttf file and click Install Font (Font Book).
  Use the files in "static" for Word, PowerPoint and design apps. The "variable" files are for the website.

WORD AND POWERPOINT THEMES (Windows)
  1. Install the fonts first (above).
  2. Copy "office/enCloud9 Colors.xml" into:
       %APPDATA%\Microsoft\Templates\Document Themes\Theme Colors
  3. Copy "office/enCloud9 Fonts.xml" into:
       %APPDATA%\Microsoft\Templates\Document Themes\Theme Fonts
     (Paste the path into the File Explorer address bar. Create the folder if it is missing.)
  4. Restart PowerPoint. Design tab > Variants > Colors > "enCloud9", and Fonts > "enCloud9".
     In Word: Design tab > Colors and Fonts.
  Mac: the theme folder location was not checked; pick the colours by hex from the Colours file instead.

SENDING FILES TO PEOPLE OUTSIDE enCloud9
  They may not have Hanken Grotesk. For anything they will edit, use Arial, or send a PDF.

EMAIL (ClickDimensions)
  Button: background #355DA6, text #FFFFFF, Arial (global font), Regular, 16 px,
  line height 2, border radius 4, aligned left.

LICENCES
  Hanken Grotesk and DM Mono are free under the SIL Open Font License 1.1. You may use them for
  anything, including commercial work, and share them inside the company. Keep the OFL.txt files
  with the fonts. The static Hanken Grotesk weights were made from the official variable font
  (Google Fonts repository), with no changes to the letter shapes.
