How do the Sales and Service Accelerators compare?

Both build a first Dynamics 365 system to a fixed scope, with users, security roles, licenses, data import and training. The Sales Accelerator builds Dynamics 365 Sales around your sales stages; the Service Accelerator builds Customer Service around your cases, queues and service levels.

When is an accelerator the wrong fit?

An accelerator is built for a first system with a standard process. If you need integrations or data from several systems on day one, or you already have a Dynamics 365 system that is not working, another package fits better.

Choose another package if

  • You need other systems connected on day one. A full implementation covers data moves and integrations.
  • You already have a Dynamics 365 system that is over-customized or stalled. Rescue and Repair is built for that.
  • You are leaving Salesforce. Move from Salesforce covers the move.
  • You need phone and chat routing for a contact center on day one. Dynamics 365 Contact Center is built for that.

How does an accelerator project run?

Every project runs through the same four stages: Plan, Build, Go live and Run. You see the written plan before we build, and every change after that is written down and approved.

Stage APlanWe learn how your team works, using a written discovery questionnaire, and give you the plan: users, stages or queues, data to move, integrations, and where Copilot and agents fit.
Stage BBuildWe build Dynamics 365 to the plan, using standard features first, and move your data. You check the imported records against your old system before sign-off.
Stage CGo liveTraining and cut-over day. Copilot is switched on if your plan includes it; agents are scoped as a separate pilot.
Stage DRunYour support plan starts. Health checks and updates are logged, so you always know what changed.

What is a Dynamics 365 accelerator?

Our accelerators are fixed-scope packages for a first Dynamics 365 system. You see the scope, price and timeline in writing before we start, and anything outside the package is a written change order you approve first.

Which accelerator do we need?

The Sales Accelerator is for a team that sells through stages, quotes or products and is starting on Dynamics 365 Sales. The Service Accelerator is for a team that handles customer requests and is starting on Dynamics 365 Customer Service.

How much does an accelerator cost?

Each accelerator is a fixed price for our build work, quoted in writing after a short call. Microsoft licenses are a separate cost, and support plans start at $500 a month.

Is the Sales Accelerator the same as the sales accelerator in Dynamics 365?

No. Microsoft's sales accelerator is a feature inside Dynamics 365 Sales that gives sellers a prioritized work list and sequences of follow-up steps. Our Sales Accelerator is a package: we build Dynamics 365 Sales for your team to a fixed scope.

What if we need more than an accelerator covers?

Anything outside the package is a written change order you approve before work starts. If you need integrations or data from several systems at go-live, a full implementation fits better.

Are Microsoft licenses included?

No. Microsoft licenses and Copilot Credits are not part of the package price, and you pay for them separately. As part of the build we assign your licenses to each user and set their security roles, because Microsoft does not let a user open the app until both are done.
