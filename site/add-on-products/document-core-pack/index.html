What is Document Core Pack?

An add-on for Dynamics 365, made by mscrm-addons, that creates documents such as quotes, contracts and reports from your CRM data using Word templates.

Can Document Core Pack send documents for e-signature?

Yes. It works with DocuSign and Adobe Sign, among others. You can set one or more signers and the signing order, and the signed copy is saved back in Dynamics 365.

Which file types can it create?

PDF and Word documents, among other formats. Templates are built in Microsoft Word.

Can it run automatically?

Yes. It can create and send documents in batches, on a schedule, or from a Power Automate flow.

How much does Document Core Pack cost?

mscrm-addons licenses it based on team size and does not publish a single price. Our setup and template work is quoted in writing.

Have you set it up for clients?

Yes. Milestone Leasing creates quotes with it, and PriceMDs uses it with Adobe Sign for e-signatures.
